# OneOhm Field

The mobile app for the OneOhm team, I&C partner crews and resellers. It is built with Expo SDK 58, React Native 0.88 and expo-router. It shares its UI kit and API client with the customer app through `@oneohm/mobile-ui`.

| Who | Sees |
|---|---|
| OneOhm team (staff) | Today, plus Leads and Quick quote when their role allows it |
| I&C partner crews | Today and their own tasks only |
| Resellers | Their own leads and Quick quote |

People sign in with their mobile number and a one-time code. In development the API uses `OTP_PROVIDER=local`, so the code is `OTP_DEVELOPMENT_CODE` (123456) and no SMS is sent.

## Run it

Start the API first (`apps/api`, port 4200). Then run:

```bash
pnpm --filter @oneohm/field start
```

### On a phone

1. Put the phone on the same Wi-Fi as the laptop.
2. Start the app with the laptop's address as the API URL:

   ```bash
   EXPO_PUBLIC_API_URL=http://<laptop-ip>:4200 pnpm --filter @oneohm/field start
   ```

3. Scan the QR code:
   - **Expo Go**: works when the Expo Go app on the phone supports SDK 58. The app only uses modules bundled in Expo Go.
   - **Development build**: use this when Expo Go is on another SDK. Run `pnpm --filter @oneohm/field android` (or `ios` on a Mac). This needs Android Studio or Xcode, or use an EAS build.

### In a browser

The browser preview is for design review and testing only. The browser calls the API directly, so the API's `CORS_ALLOWED_ORIGINS` must include `http://localhost:8081`.

```bash
EXPO_PUBLIC_API_URL=http://127.0.0.1:4200 pnpm --filter @oneohm/field web
```

## Production

Set `EXPO_PUBLIC_API_URL=https://<your domain>/api` when building. Native projects are generated by `expo prebuild` and are not committed. The app id is `in.oneohm.field`.

The app icon is made from the 256-pixel brand mark. Replace `assets/images/icon.png`, `adaptive-icon.png` and `splash-icon.png` with high-resolution artwork before publishing to the stores.
